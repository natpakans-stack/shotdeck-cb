Last updated: 12 September 2026

Who we are

ShotDeck is a personal, single-user tool operated by the owner of the channel แกะเรื่องเล่า · Baa-sics. It is not offered to the public and has no other users. Contact: tanjamza113@gmail.com

What data is accessed

With the owner's explicit sign-in, ShotDeck reads from the connected platforms (YouTube, Facebook, Instagram, TikTok): the list of the owner's own videos and posts, their public statistics (views, likes, comments, shares, average watch time, audience retention) and channel-level counts (subscribers or followers). For YouTube this uses the YouTube Data API and YouTube Analytics API with read-only scopes.

How data is used

The data is displayed to the owner in a dashboard to plan future content. It is not used for advertising, profiling, or any purpose other than showing the owner their own statistics.

Where data is stored

All data and access tokens are stored only on the owner's own computer. Nothing is transmitted to third parties, sold, or shared. This website stores nothing; it only forwards sign-in redirects to the local application.

Google API Services

ShotDeck's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time from the platform's account settings (for Google: myaccount.google.com/permissions). Revoking access stops all data reading; locally stored data can be deleted by the owner at any time.
